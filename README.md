# Single-Snapshot-Calibration-and-3D-Reconstruction

This project focuses on achieving high-precision visual calibration and 3D reconstruction using a single snapshot, primarily designed for omnidirectional vision systems and robotic localization tasks.

## 🛠 Features

* **Single-Snapshot Calibration**: Complete camera intrinsic or structured light parameter calibration using only one image.
* **3D Reconstruction**: Feature extraction from a single frame to achieve 3D point cloud reconstruction of target objects.
* **Robotics Integration**: Supports SCARA robot motion trajectory planning and obstacle avoidance experiments.
* **Multi-Platform Support**: Combines MATLAB for algorithm verification, Python (PyVista) for data processing, and Unity3D for visual localization simulation.
